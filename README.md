# Planetario TailPress

A TailPress-inspired WordPress theme for Planetario Realty and Brokerage Services Inc.

## Development

```bash
cd wp-content/themes/planetario-tailpress
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The theme includes fallback CSS and JS in `public/` so it can be activated before the Vite build is generated.
